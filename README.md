# Where to Poop Public Pages

Static support, privacy, and community pages for the Where to Poop iPhone app.

## Required App Store URLs

- `https://wheretopoop.app/support`
- `https://wheretopoop.app/privacy`
- `https://wheretopoop.app/community`

## GitHub Pages Settings

Use GitHub Pages from the `main` branch and root folder.

The `CNAME` file configures the custom domain as `wheretopoop.app`.
